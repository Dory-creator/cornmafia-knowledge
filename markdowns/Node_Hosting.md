Node Hosting
============

Empowering players and decentralizing parts of the gaming ecosystem

Players have the opportunity to run file nodesin Infinity Rising. Users can host their own games and help support critical infrastructure.

Players purchase a license to run an Infinity Rising node. There are a number of Host-and-Earn nodes that will be available for players to own and run themselves - more information can be found in the [Node](/the-company/technology/nodes) section.

This is essential tothe decentralized element of Infinity Rising. It gives power and connectivity to the users. Hosting occurs on players PCs and is an add-on feature available to support the the game [Launcher](/gameplay/game-launcher) and main game.
