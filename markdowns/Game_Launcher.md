Game Launcher
=============

The Game Launcher helps users start Infinity Rising and once installed its available as an icon on the user's desktop PC or laptop - it is the starting point for the adventure into the Infinity Rising metaverse.

The Launcher is more than just a shortcut. It will offer the following when development is fully completed:

* **Game Installation -** one of the main functions of the Launcher is to download the game using the decentralized game distribution network hosted by players themselves. More information can be found here on how to run your own [File Node](/the-company/technology/nodes/file-nodes).
* **Library -** allows players and in house developers to start various versions of the [PC Game](/gameplay/gameplay-pc) e.g. demo versions, staging/live etc.
* **Player Owned Wallet**- an advanced integrated player owned wallet.
* **News** - news and event notices.

### Multi-Chain Players Wallet

The Launcher is a custom built compatible Cardano and Base Chain wallet. The wallet is capable of the following features:

* Connect an existing Cardano and Base wallet to an Infinity Rising account so the game will be able to recognize, authorize and integrate player owned assets;
* View and interact with NFTs in a familiar environment, search, sort, expand, watch videos, follow links, view statistics, interact with 3D objects. \*
* During development, the Launcher will be able to switch from the Infinity Rising Live and Staging environment \*

***\* future development update***

### Security

The Launcher will have security as its number one priority and the code will be independently tested and audited before launch.

### Connectivity

The Launcher works in the background alongside the [Unreal Engine](/the-company/technology/unreal-engine-5-ue5) game to provide services such as blockchain functionality, [server connectivity,](/the-company/technology/nodes) and other API interactions that are better suited to be developed within a desktop application than a games engine.

The Launcher will be updated and will grow into an invaluable piece of critical infrastructure.
