Valley Raceworx T1
==================

The Valley Raceworx T1 is NOT a Player Owned Asset and all models will be available to use in game for everyone

The Valley Raceworx T1 is a flying vehicle that was built just for racing and can be raced in [Calido Valley](/gameplay/mega-dome-calido-valley/calido-valley-resort).

It comes in 3 different models that can be raced in 3 different race classes - A, B and C. There is a lot that goes into the Class system to keep them balanced for racing.

![](https://copiwiki.cornucopias.io/~gitbook/image?url=https%3A%2F%2F4046923609-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FPQmCVki2WHg9QcW9pdrX%252Fuploads%252Fs55Q5rMDw7Ub7J50vWzw%252Fimage.png%3Falt%3Dmedia%26token%3D6020d526-25b0-432d-ab14-6f331b582fde&width=768&dpr=4&quality=100&sign=5c7914fb&sv=2)

A deep dive into the 3 different T1s can be seen in [COPI Cafe](/gameplay/community/copicafe-archive-videos) Episode 58.

Difference in Class
-------------------

### Class C

Class C is the entry level and the slowest of the T1s. It has the best handling of all 3.

![](https://copiwiki.cornucopias.io/~gitbook/image?url=https%3A%2F%2F4046923609-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FPQmCVki2WHg9QcW9pdrX%252Fuploads%252Fe6GCgs9TA7vDGDqFE0fv%252Fimage.png%3Falt%3Dmedia%26token%3D6baf595d-c89a-4914-a725-e8081ae9c33f&width=768&dpr=4&quality=100&sign=69e9d6b3&sv=2)

### Class B

The T1 - Class B has reverse thrusters making breaking fun and exhilerating. It has a faster top speed than the T1 - C Class. It also has an Aero Braking kit.

![](https://copiwiki.cornucopias.io/~gitbook/image?url=https%3A%2F%2F4046923609-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FPQmCVki2WHg9QcW9pdrX%252Fuploads%252Fs6oW8qvoUXcnHt8hpEy2%252Fimage.png%3Falt%3Dmedia%26token%3De047a99d-e2e3-49bf-85ce-6869efc46fa1&width=768&dpr=4&quality=100&sign=9d766976&sv=2)

### Class A

The T1 - Class A has reverse thrusters making breaking fun and exhilerating. It has a faster top speed than the T1 - B Class and C Class.

![](https://copiwiki.cornucopias.io/~gitbook/image?url=https%3A%2F%2F4046923609-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FPQmCVki2WHg9QcW9pdrX%252Fuploads%252Fl3e1ktLgxFSfolhbEbas%252Fimage.png%3Falt%3Dmedia%26token%3Dacfc2bb8-999e-4fde-9b82-4f5d552afe37&width=768&dpr=4&quality=100&sign=a48f5cba&sv=2)
