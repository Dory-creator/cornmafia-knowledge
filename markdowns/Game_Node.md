Game Node
=========

When a player plays the PC version of Infinity Rising they always need to join the Infinity Rising network - this is done via an Unreal Engine Server Instance.

During gameplay the player may join and disconnect from many Game Nodes - for example, when joining a mini-game, the player will connect to the Game Node that the mini-game is being played on before re-joining the main Game Node they were on before.

The coordination of the node servers is done using the [Data Node](/the-company/technology/nodes/data-node).

Infinity Rising uses Data Nodes and Game Nodes for many functions.

### **Game Node Rewards**

Game Nodes require a game node license to run. This establishes the player as a Game Node operator and allows their PC to participate in Infinity Rising decentralization.

In return for hosting a Game Node, players will be rewarded with $RISE and/or other rewards. Rewards will be based on the up-time and the performance of the Game Node.
